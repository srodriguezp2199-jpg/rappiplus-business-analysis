# 📓 Notebook

Esta carpeta contiene el notebook principal del proyecto **RappiPlus | End-to-End Business Analysis**.

El notebook documenta el proceso de análisis desarrollado con Python y SQL, incluyendo preparación de datos, análisis exploratorio, análisis de negocio, funnel de conversión, retención y evaluación estadística.

El proyecto fue desarrollado como proyecto final del programa de Análisis de Datos de TripleTen.
