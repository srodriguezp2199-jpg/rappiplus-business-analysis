# 📊 Dashboard de Power BI

Esta carpeta contiene el dashboard desarrollado en Power BI como parte del proyecto **RappiPlus | End-to-End Business Analysis**.

El dashboard permite visualizar los principales indicadores obtenidos durante el análisis y explorar el desempeño del negocio mediante visualizaciones interactivas.

## Contenido

- Indicadores clave de desempeño (KPIs)
- Evolución temporal de los principales indicadores
- Análisis de ventas e ingresos
- Análisis de rentabilidad
- Desempeño por producto

## Herramientas

- Power BI
- DAX
- Power Query

> El dashboard forma parte del proyecto final desarrollado durante el programa de Análisis de Datos de TripleTen.
